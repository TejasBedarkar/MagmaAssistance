# openai-whisper depends on numba, and versions of numba before 0.61 cap
# numpy<2.1 -- since numpy never shipped a prebuilt wheel for that <2.1 range
# on Python 3.13, pip would otherwise backtrack to a wheel-less numpy 2.0.x

# release that supports both Python 3.13 and numpy>=2.1, so pinning it
# avoids that backtrack entirely.

# Pinned explicitly: kokoro -> misaki[en] -> spacy has no upper bound, so pip
# can otherwise resolve the wheel-less spacy 4.0.0.dev pre-release, which
# then tries to compile blis/thinc from source and fails on Python 3.13
# (Cython/numpy header mismatch). >=3.8 also matters on its own: older
# spacy 3.7.x pulls a blis/thinc pair that caps numpy<2.0, and since numpy
# never shipped an official <2.0 wheel for Python 3.13, pip falls back to
# building numpy from source with whatever MinGW compiler is on PATH --
# producing the "Numpy built with MINGW-W64 ... experimental" crash warning.
# spacy>=3.8 pulls blis/thinc that support numpy>=2, which has real wheels.
spacy>=3.8,<4
